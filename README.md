# Bluetoothによる距離測定のサンプル

コードは主に/src/main.cppに書かれている

軽い説明もコメントとして残してある

## 距離に対するRSSI(信号強度)

環境によっておそらく大きく変動することに留意する

|距離|RSSI|
|----|----|
|数cm|-20~-40 dBm|
|1m|-50~-60 dBm|
|3m|-60~-70 dBm|
|5m|-80~-90 dBm|

これ以上の距離は未検証

## 所感

RSSIは結構揺れる

環境にもよるだろうが +-10 dBm くらいは軽く揺れる

実際に使う場合は数回の平均をとったりする必要がありそう

近くでほかのBluetoothデバイス使うと強度がシフトしたりもしそう

ただ今回のプロジェクトで使う分には十分な性能を発揮できるのではないかと思う
